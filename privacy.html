Privacy policy

Draft dated 27 November 2026. Contact and operational controls must be verified before submission.

1. Operator and scope

Independent individual project in the Republic of Korea. This policy covers the static information website and intended internal read-only research client using YouTube API Services.

2. Data accessed

This site has no registration, forms, advertising, analytics scripts or application cookies. Hosting providers may process ordinary technical request information under their own policies. The intended client accesses public video IDs, titles, dates, comments, replies and related public metadata through YouTube Data API v3. Comment text may incidentally contain personal information. No private account information, passwords or visitor OAuth authorization are requested.

3. Purpose and processing

Research into information-seeking behavior and unmet information needs, which may inform future consumer information services. Large-scale cross-channel processing and derived analysis are on hold unless permitted by YouTube. We intend to minimize data, omit author identifiers, redact personal details, restrict access to authorized local operators and avoid individual profiling or sensitive-data targeting. Redaction does not guarantee anonymity.

4. Retention and deletion

Non-authorized API data will be deleted or refreshed within the applicable YouTube policy deadline, generally no later than 30 calendar days unless an applicable exception permits otherwise. Raw comment records will not be published. Unnecessary data will be removed. Deletion and renewal procedures must be verified before expanded collection; no automatic retention control is claimed to be operating yet.

5. Sharing and security

No sale of raw comment records or disclosure for advertising is intended. Authorized processing must comply with the disclosed purpose and applicable policy. API keys are not displayed. Access and security controls will be reviewed before production use.

6. Requests and contact

Individuals may request information, correction or deletion where applicable. A working private contact channel must be confirmed before application submission. The operator profile identifies the operator. Do not submit personal or financial details via public issues.

7. Platform policies

This client uses YouTube API Services. See Google's Privacy Policy, YouTube Terms of Service, YouTube API Developer Policies and Google account permissions if applicable.
